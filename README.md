# Сводка — карта сообщений

Демонстрационный сайт для анализа архивных гражданских сообщений: импорт → извлечение сведений → проверка мест → карта с цветами по давности.

## Запуск

1. Установите Python 3.10+ и Ollama, если они ещё не установлены.
2. В Ollama должна быть доступна модель `qwen3:4b` (`ollama pull qwen3:4b`). Можно выбрать другую локальную модель в настройках сайта.
3. Запустите `start-local.cmd` и откройте **http://127.0.0.1:8765**.
4. Выберите файл, укажите дату сообщений без даты, оставьте «Локальная LLM · Ollama» и нажмите «Анализ событий».

Никаких ключей API, платных сервисов и Python-пакетов для приложения не требуется. Загрузка подложки OpenStreetMap требует интернета.

## Возможности

- Подвижная карта с масштабированием и обзором России.
- TXT, CSV, JSON, DOCX и ZIP до 10 МБ. Для приложенного OSM.zip выбирается report.txt; производный coords.txt не используется.
- Настоящее структурированное извлечение через локальную Ollama. Отдельно доступен явно обозначенный режим без LLM — поиск по справочнику.
- Справочник населённых пунктов Башкортостана из предоставленного пользователем CSV. География карты шире географии справочника: записи с явными координатами могут находиться в других регионах.
- Исходное сообщение, время, источник, способ разбора и основание координат в карточке.
- До 15 минут — коралловый, 15–60 минут — жёлтый, 1–3 часа — синий, старше 3 часов — серо-синий. Нет времени — серый, позже момента анализа — фиолетовый.
- Момент архивного анализа задаётся шкалой. Давность считается от него, а не от часов компьютера.
- Несколько сообщений из одного места сохраняются по отдельности в общей карточке точки.
- Неоднозначные названия, несколько мест в сообщении и ошибки координат направляются в журнал проверки; доступен ручной выбор места.
- Поиск по журналу и выгрузка всех записей в JSON.

## Как интерпретировать время и место

Время из текста — время, указанное в сообщении; оно не выдаётся за достоверное время регистрации звонка. Если дата отсутствует, используется явно выбранная дата импорта и это помечается в карточке. Автоматического перехода через полночь нет: при данных за несколько суток добавьте даты в исходный файл. Часовой пояс — Asia/Yekaterinburg, UTC+5. Неизвестное время не подменяется текущим.

Точка по справочнику обозначает центр населённого пункта, а не точную позицию события. LLM не генерирует координаты: предложения модели сверяются с локальным справочником. Неизвестные места не появляются на карте до уточнения. Совпадающие названия в разных районах требуют уточнения района.

Демонстрация предназначена для журнала и ретроспективного анализа гражданских сообщений. Расчёты траекторий, направлений полёта, скоростей, мест запуска, объединение сообщений в треки и подключение к оперативным потокам отсутствуют.

## Форматы

TXT: одно сообщение на строку. DOCX: один абзац на сообщение. В CSV и JSON поддерживаются поля:

| Поле | Примеры имён |
| --- | --- |
| Исходный текст | text, message, сообщение, текст |
| Время | timestamp, datetime, time, время |
| Место | place, settlement, населённый пункт |
| Район | district, район |
| Координаты | lat / lon, latitude / longitude, широта / долгота |
| Источник | source, источник |

Для однозначного времени удобнее ISO 8601, например `2026-10-15T09:28:00+05:00`. Экспорт JSON можно загрузить обратно.

## Публикация на GitHub Pages

1. Скопируйте проект в новый репозиторий.
2. Выполните `python prepare_pages.py` и добавьте папку `docs` в Git: `git add -f docs`.
3. В Settings → Pages выберите Deploy from a branch → main → /docs.

Публичный сайт содержит только интерфейс, справочник и **вымышленные** демонстрационные сообщения. Оригинальные отчёты, DOCX и аудиозапись в проект не включены. Загружаемые в браузере файлы на GitHub не отправляются.

GitHub Pages публикует интерфейс. Для анализа локальной моделью на компьютере оператора должен работать `local_server.py`; в настройках опубликованного сайта адрес `http://127.0.0.1:8765`. Браузер может запросить разрешение на локальное подключение. Альтернативно откройте сам сайт локально — так подключение к модели не требует межсайтового запроса.

Локальный помощник слушает только 127.0.0.1, разрешает свой адрес и https://azattau.github.io. Для другого домена используйте `python local_server.py --allow-origin https://your-domain.example`. Содержимое сообщений не пишется в журналы и не сохраняется сервером. На общей машине доступ к запущенному помощнику имеют другие локальные приложения.

## Проверка

`node --test tests/core.test.cjs` — обработка CSV, времени, неоднозначных названий, повторов и экспорта. `python -m unittest discover -s tests -p "test_*.py"` — проверка локального помощника.
